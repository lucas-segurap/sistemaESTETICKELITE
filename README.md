# 🚗 EstetickElite

**Sistema de gerenciamento para estética automotiva**

O **EstetickElite** é um sistema desenvolvido para auxiliar no gerenciamento de uma empresa de estética automotiva, facilitando o controle de clientes, serviços e agendamentos.

O projeto foi desenvolvido como parte das atividades do curso de **Desenvolvimento de Sistemas**, com o objetivo de aplicar na prática conhecimentos de programação, banco de dados, desenvolvimento web e organização de projetos.

---

## 📌 Sobre o projeto

A EstetickElite busca oferecer uma forma mais organizada e prática de administrar os serviços de uma estética automotiva.

O sistema permite centralizar informações importantes, tornando o atendimento aos clientes mais organizado e facilitando o gerenciamento dos serviços oferecidos.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver um sistema que auxilie a EstetickElite no gerenciamento de seus serviços e clientes, proporcionando:

* 📅 Organização dos agendamentos;
* 👤 Cadastro e gerenciamento de clientes;
* 🚗 Controle dos serviços realizados;
* 📋 Consulta de informações;
* 💬 Facilitação da comunicação com os clientes;
* 📊 Melhor organização das informações da empresa.

---

## ⚙️ Funcionalidades

### 🏠 Página Inicial

Apresentação da empresa e dos principais serviços oferecidos.

### 👤 Cadastro

Permite realizar o cadastro de clientes no sistema.

### 📅 Agendamento

Possibilita realizar e organizar agendamentos de serviços.

### 🚘 Serviços

Apresentação dos serviços disponibilizados pela EstetickElite.

### 📦 Pacotes

Exibição dos pacotes de serviços oferecidos pela empresa.

### 📜 Histórico

Consulta dos serviços e informações relacionadas aos atendimentos realizados.

### 📞 Fale Conosco

Área destinada ao contato entre clientes e a empresa.

---

## 💻 Tecnologias utilizadas

As tecnologias utilizadas no desenvolvimento do projeto incluem:

* **HTML5** — estrutura das páginas;
* **CSS3** — estilização e layout;
* **Java** — desenvolvimento da aplicação;
* **Spring Framework** — desenvolvimento do back-end;
* **Banco de Dados** — armazenamento das informações;
* **Git e GitHub** — versionamento e gerenciamento do código.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd EstetickElite
```

### 3. Configure o banco de dados

Crie o banco de dados utilizado pelo projeto e configure as informações de conexão na aplicação.

### 4. Execute o projeto

Inicie o back-end e, em seguida, abra a aplicação pelo navegador ou pela ferramenta utilizada no desenvolvimento.
